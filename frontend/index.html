使用说明

按「导入 → 自检 → 润色 → 复核导出」闭环使用，四个步骤在左侧切换。

  • 自检报告：行文特征指数由句式均匀度、用词重复、套话密度与高频句式四项加权得到，并列出命中证据，可复现、可追溯；配合统计判别器读数一起定位需要修订的段落。
  • 两种分析方式：自检面板右上角可切换。「本地规则」毫秒级、离线，刻画可见的行文特征；「模型评估 · GLM」由模型逐段给出风格线索与理由，较慢且有一定波动。两者都用于修订定位。
  • 口径说明：本工具量化的是行文特征，机构检测系统另有一套数据与判定标准，读数不具可比性。指数低表示当前特征不明显，不作为任何外部判定的替代。
  • 原意保护：引用标注、百分比、单位数值、公式、英文缩写与自定义保护词会逐字锁定；被破坏的段落自动回退原文。
  • 复核导出：可逐段「换一种写法」、手动编辑全文，再复制或导出 .txt / Word(.doc) / 对比报告 .md / 可视化报告 .html；导出内容以当前编辑后的文本为准。
能力边界：本工具提供行文特征的量化体检与修订建议，不生成或仿造任何机构检测报告，不提供相似度或来源匹配数据，也不对文本来源作判定。请以所在机构认可的结论与人工复核为准。
