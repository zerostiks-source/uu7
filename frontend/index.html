使用说明

按「导入 → 自检 → 润色 → 复核导出」闭环使用。

  • 自检报告：信号强度由句式均匀度、用词重复、套话、AI 高频句式四项加权得到，并列出命中的句式证据；这是启发式规则，不是 AI 生成概率，也不是官方检测结论。
  • 能力边界：规则库只能覆盖可枚举的模板化表达。官方检测器基于语言模型概率与分类器，判定依据不同，因此出现「官方标红、这里分数低」是能力差异，不是检测通过。
  • 两种引擎：本地规则引擎离线可用，做保义的措辞与句式优化；在 backend/providers.json 或环境变量中配置模型后，自动/手动切换为深度语义改写。
  • 中英双语路由：默认逐段识别语言，中文段与英文段各用一套供应商、system prompt 与强度/风格指南；可在「处理语言」强制整篇按中文或英文处理。中英文信号口径不同，不宜横向比较分数。
  • 原意保护：引用标注、百分比、单位数值、公式、英文缩写与自定义保护词会逐字锁定；被破坏的段落自动回退原文。
  • 精准润色：只处理信号较强的段落，合格内容完全不动，减少无效改动。
  • 复核导出：可逐段「换一种写法」、手动编辑全文，再复制或导出 .txt / Word(.doc) / 对比报告 .md / 可视化报告 .html；导出内容以当前编辑后的文本为准。
  • 可视化报告：自有命名的自检报告，包含处理信息、整体信号、指标拆解、命中证据、逐句定位与逐段对照，打开后 Ctrl+P 可存为 PDF。报告固定带有能力边界声明，明确不是任何官方检测结果，不可作为检测证明或提交材料。
本工具不判定文本是否由 AI 生成，也不保证通过任何检测；不生成、不仿造任何官方检测报告，也不提供相似度或来源匹配数据。请以官方检测报告与人工判断为准，逐句核对语义、数据与引用，并遵守所在机构的学术诚信规定。
