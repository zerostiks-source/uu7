# Spec Delta

## Purpose

让部署方能够接入并切换不同的大语言模型供应商，避免系统绑定单一供应商。

## ADDED Requirements

### Requirement: 多供应商接入

系统 SHALL 通过统一的模型接入配置支持接入多家大语言模型供应商。

#### Scenario: 接入多个供应商

- **WHEN** 部署方配置了一家或多家大语言模型供应商
- **THEN** 系统可按配置使用其中任一家供应商执行改写

#### Scenario: 新增供应商

- **WHEN** 部署方新增一家供应商的配置
- **THEN** 系统能够使用该供应商，无需改动业务逻辑

### Requirement: 供应商切换

系统 SHALL 支持在不同供应商之间切换，切换后改写功能正常工作。

#### Scenario: 切换供应商后改写

- **WHEN** 部署方将当前供应商切换为另一家已配置的供应商并触发改写
- **THEN** 系统使用切换后的供应商完成改写，功能正常

#### Scenario: 未配置任何可用供应商

- **WHEN** 系统未配置任何可用的模型供应商且用户触发改写
- **THEN** 系统明确提示未配置模型供应商，不执行改写

### Requirement: 供应商调用参数可配置

系统 SHALL 允许配置供应商的模型与调用参数，以适应不同供应商的能力与限制。

#### Scenario: 配置模型与参数

- **WHEN** 部署方为某供应商配置模型名称与调用参数
- **THEN** 系统按该配置调用模型，配置变更后无需修改业务逻辑即可生效
