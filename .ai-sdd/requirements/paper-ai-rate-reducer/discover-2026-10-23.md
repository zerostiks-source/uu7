> 采集日期：2026-10-23
> 采集轮次：第 1 轮

---

## 一、需求概述

构建一个面向个人学生自助使用的 Web 工具，用于降低学术论文的 AI 生成率检测结果。用户上传或粘贴论文文本（支持文本/Markdown、Word .docx、PDF），工具先做 AI 痕迹自检（内置代理评分 + 可选对接官方检测接口），再通过可配置的 LLM 多供应商适配层做语义保持改写，提供轻/中/重多档改写强度，并锁定专业术语、引用文献、数据与公式以保护原意，最终输出改写前后对比供用户核验与导出。全程免登录，会话内使用。

### 4.2 补充设计约束

| # | 约束项 | 决策 | 理由 |
|---|--------|------|------|
| 1 | 改写引擎 | LLM 语义改写为核心，通过供应商适配层抽象 | 效果优先，且需多供应商可配置 |
| 2 | 供应商适配 | 统一 Provider 接口，支持国内/海外多家模型 | 部署灵活、避免锁定单一供应商 |
| 3 | 改写强度 | 轻/中/重三档，映射到不同 prompt 策略与改写幅度 | 用户对“改动多少”有不同诉求 |
| 4 | 原意保护 | 改写前识别并锁定术语/引用/数据/公式，改写后校验未被破坏 | 学术文本不容许术语与数据被篡改 |
| 5 | 检测能力 | 内置代理评分（困惑度/突发性等），可选对接官方检测 API | 免登录下快速反馈 + 可选权威校验 |
| 6 | 交付形态 | Web 应用（前后端分离，同仓库管理） | 用户自助、易用 |
| 7 | 隐私 | 不持久化用户论文原文，仅会话内处理 | 免登录 + 学术内容敏感 |
| 8 | 长文本 | 按段落/章节分段批处理，流式返回进度 | 学位论文篇幅长，单次请求不现实 |

**详细内容：**

- **Provider 适配层**：定义统一的 `LLMProvider` 接口（`rewrite(text, strength, constraints) -> text`），具体实现按供应商封装鉴权、模型名、超参；通过配置切换，禁止业务代码直接依赖某家 SDK。
- **锁定机制**：改写前用规则（正则匹配引用格式如 `[1]`、`(Author, 2020)`）+ 术语词表 + 可选 NER 识别锁定跨度；改写 prompt 中显式声明锁定项；改写后比对锁定跨度是否逐字保留，否则标记失败并回退原文。
- **强度映射**：轻度=同义/句式微调；中度=句序重排 + 表达重构；重度=段落级重写。强度只影响改写 prompt 与允许的编辑距离，不影响锁定项。
- **分段与限流**：按段落切分（保留章节标题结构），并发受供应商限流约束，失败段落指数退避重试；汇总为整体结果。
- **官方检测对接**：抽象为可插拔的 `DetectorAdapter`，未配置时仅用内置代理评分；对接需用户提供授权凭据。

### 4.3 补充需求澄清

| # | 澄清项 | 原始模糊点 | 澄清结论 |
|---|--------|-----------|---------|
| 1 | 目标用户 | “工具”面向谁 | 个人学生自助使用，不做机构批量与多租户 |
| 2 | 检测基准 | 降低谁的 AI 率 | 中文以知网/维普等为准，英文以 Turnitin 等为准，二者均为优化目标 |
| 3 | 交付形态 | 形态未定 | Web 应用 |
| 4 | 账号 | 是否需登录 | 免登录，会话内使用 |
| 5 | 格式 | 支持哪些格式 | 文本/Markdown、Word .docx、PDF（导入） |

**详细内容：**

- 工具为个人自助型 Web 应用，核心价值是“检测 → 改写 → 对比 → 导出”闭环。
- 不解决“规避学术审查”的合规责任问题，产品需明确提示用户遵守所在机构的学术诚信规定。
- 导出格式应与导入格式能力对齐（docx/pdf 导入至少支持导出改写后的文本/docx）。

### 4.4 原型

| # | 原型内容 | 来源 | 说明 |
|---|---------|------|------|
| 1 | 主工作区：左侧文本输入/上传，中间检测评分，右侧改写结果 | 用户口述 | 三段式布局 |
| 2 | 改写前后对比视图（差异高亮） | 用户口述 | 便于用户核验改动 |

**详细内容：**

- **主页面布局**：顶部为工具名与设置入口；主体三栏——输入区（粘贴/上传 + 格式提示）、分析区（AI 率代理评分 + 分段明细）、结果区（改写后文本 + 强度切换 + 复制/导出）。
- **对比视图**：改写前后左右对照，变更片段高亮；锁定项以不同颜色标注且不可编辑。
- **交互**：上传 → 自动解析 → 点击“检测”得代理评分 → 选强度 → 点击“改写” → 流式返回 → 对比核验 → 导出。
