# 安全与合规规范（Security Rules）

> 本文记录通用安全要求和项目待确认项。真实账号、token、密钥、证件号、手机号、地址和生产报文不得写入 context。

---

## 一、输入安全

| 规则 | 要求 | 说明 |
|------|------|------|
| 参数校验 | 校验必填、长度、格式、枚举和字段组合 | 前端校验不能替代后端权威校验 |
| SQL 安全 | 使用参数绑定或框架查询条件 | 禁止拼接用户输入 |
| 文件/附件 | 校验类型、大小、路径和扫描结果 | 禁止信任文件名和扩展名 |
| 外部报文 | 校验签名、来源、时间戳和重放风险 | 失败应记录审计但不泄露细节 |

---

## 二、认证与授权

| 规则 | 要求 | 说明 |
|------|------|------|
| 登录态 | 页面接口必须确认登录态或调用身份 | 失效时返回统一错误 |
| 操作权限 | 业务动作需校验角色、菜单、按钮或权限实体 | 权限来源以项目模型为准 |
| 数据权限 | 按组织、渠道、区域、租户或数据归属限制访问 | 不在前端单独依赖隐藏按钮 |
| 服务间调用 | 跨系统调用需有认证、签名或白名单机制 | 以目标项目安全规范为准 |

---

## 三、数据保护

| 数据类型 | 保护要求 | 处理方式 |
|---------|---------|---------|
| 个人身份信息 | 最小化采集、展示脱敏、日志禁明文 | 只保留后四位、哈希或占位 |
| 联系方式 | 页面展示和日志脱敏 | 测试数据使用虚构占位 |
| 账号/token/密钥 | 禁止写入代码、日志和 context | 使用配置中心或密钥管理 |
| 业务敏感数据 | 按权限和场景控制查询范围 | 记录审计和访问来源 |

---

## 四、日志安全

| 规则 | 说明 |
|------|------|
| 异常日志 | 记录排障信息，但不输出敏感字段明文 |
| 请求响应 | 只记录摘要、traceId、服务码、耗时和错误码 |
| 审计日志 | 关键操作记录操作人、组织、时间、对象和结果 |
| 测试日志 | 不上传包含真实客户、密钥或生产报文的日志 |

---

## 五、合规与上线检查

| 合规项 | 要求 | 说明 |
|--------|------|------|
| 最小权限 | 新增接口、菜单、按钮和服务账号按最小权限授权 | 上线前确认权限清单 |
| 数据脱敏 | 页面、接口、日志、测试数据均需脱敏策略 | 与安全规范保持一致 |
| 可追溯 | 关键业务操作和外部调用保留 trace 和审计证据 | 便于问题追踪 |
| 安全测试 | 覆盖越权、注入、重放、敏感信息泄露等场景 | 高风险变更必须验证 |
