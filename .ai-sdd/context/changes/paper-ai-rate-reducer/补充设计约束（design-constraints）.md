---

## 一、架构约束

| # | 约束项 | 决策 | 理由 |
|---|--------|------|------|
| 1 | 交付形态 | Web 应用，前后端分离、同仓库管理 | 用户自助、易用 |
| 2 | 技术栈 | 后端 Python + FastAPI；前端 Vue 3 + Vite | 与 project-profile 一致 |
| 3 | 改写引擎 | LLM 语义改写为核心 | 效果优先 |
| 4 | 供应商适配 | 统一 `LLMProvider` 接口，支持国内/海外多家模型，配置切换 | 部署灵活、避免锁定单一供应商 |
| 5 | 检测能力 | 内置代理评分 + 可插拔 `DetectorAdapter`（可选对接官方检测 API） | 免登录下快速反馈，官方校验可选 |

---

## 二、Provider 适配层

- 定义统一接口，例如 `rewrite(text, strength, constraints) -> text`。
- 具体实现按供应商封装鉴权、模型名、超参；通过配置切换。
- **禁止业务代码直接依赖某家 SDK**，必须经适配层。

---

## 三、锁定机制（原意保护）

| 环节 | 做法 |
|------|------|
| 识别 | 改写前用规则（正则匹配引用格式如 `[1]`、`(Author, 2020)`）+ 术语词表 + 可选 NER 识别锁定跨度 |
| 声明 | 改写 prompt 中显式声明锁定项，要求模型逐字保留 |
| 校验 | 改写后比对锁定跨度是否逐字保留，未保留则标记失败并回退原文 |

---

## 四、改写强度映射

| 档位 | 策略 |
|------|------|
| 轻度 | 同义/句式微调 |
| 中度 | 句序重排 + 表达重构 |
| 重度 | 段落级重写 |

> 强度只影响改写 prompt 与允许编辑距离，**不影响锁定项**。

---

## 五、长文本处理与限流

- 按段落切分（保留章节标题结构），并发受供应商限流约束。
- 失败段落指数退避重试；汇总为整体结果。
- 流式返回进度，提升长文体验。

---

## 六、隐私与合规

- 不持久化用户论文原文，仅会话内处理（免登录场景）。
- 产品层需明确提示用户遵守所在机构学术诚信规定。
