# {change-name} 专属上下文 README

> 目录说明：本目录用于存放单个 change 的专属上下文。目录名应与 OpenSpec change 名一致；本结构只定义加载规则和文件清单格式，不预设任何具体业务事实。

## 文件清单与加载策略

| 文件 | 内容 | 加载时机 |
|------|------|----------|
| 待补充 | change 专属接口契约、报文、字段映射、补充约束或外部协商材料 | 当前 change 命中对应场景时按需加载 |

## 强制门禁

- 只在处理同名 change 时加载本目录内容。
- change 专属上下文优先级高于通用结构，但不能覆盖用户当前明确说明。
- 若与源码、API Registry、GitNexus 或用户说明冲突，必须记录冲突并暂停写确定结论。

## 推荐加载顺序

1. 先读本 README，确认本 change 的专属资料范围。
2. 再按当前阶段和问题加载接口契约、字段映射、报文样例、外部协商稿等具体文件。
3. 最后结合通用 context 和源码证据形成设计或实现结论。

## 延迟加载建议

- 未命中当前问题的专属资料不要预加载。
- 大型原始材料先读摘要/索引，再按字段、接口、报文或场景下钻。

## 停止继续加载建议

- 当前问题已找到直接证据后停止继续展开无关文件。
- 进入 apply 后，只保留与当前任务直接相关的专属约束。
