# 共享组件库约定（Shared Components）

本文档描述 `type=components` 仓库的管理约定。

---

## 定义与特征

- **共享组件库**是可被工作区内多个仓库通过**构建期依赖**直接引用的公共模块。
- 引用方式为 import / require / Maven dependency / npm package 等本地或私服包依赖，**不经过** CSF / HTTP / RPC 等远程调用。
- 变更组件库时，需评估所有消费方的兼容性影响。

## 兼容性约定

| 变更类型 | 处理方式 |
|----------|----------|
| 新增导出 | 次版本号递增；消费方无需改动 |
| 修改已有导出签名 | 主版本号递增；需同步更新所有消费方 |
| 删除导出 | 主版本号递增；需先确认无消费方使用 |
| 内部重构（不改导出） | 补丁版本号递增；消费方无感知 |

---

## 变更影响评估

修改 components 仓库时，必须：
1. 运行 GitNexus impact analysis 识别消费方。
2. 在 design/tasks 中列出受影响的消费方仓库及需要的适配改动。
3. 若为破坏性变更（主版本号递增），需在 proposal 阶段明确说明迁移计划。
