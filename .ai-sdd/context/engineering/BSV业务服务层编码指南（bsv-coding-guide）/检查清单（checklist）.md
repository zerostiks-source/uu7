# 检查清单（Checklist）

> 本文用于 BSV/业务服务层设计和编码自检。具体接口名、包路径、datasource、服务注册和测试命令必须以目标仓库为准。

---

## 一、分层与职责

| # | 检查项 |
|---|--------|
| 1 | 门面层只做协议适配、参数校验、异常转换和响应包装 |
| 2 | 业务编排层承载业务规则、事务边界、幂等和下游编排 |
| 3 | DAO/Engine 只做数据访问，不承载页面语义和跨系统流程 |
| 4 | 跨中心/外部调用经过适配层封装 |
| 5 | 新增能力已说明是否复用既有 SV/API |

---

## 二、数据访问与路由

| # | 检查项 |
|---|--------|
| 1 | 表、字段、枚举、datasource 和 `.bo` 有证据 |
| 2 | DAO 包路径与 defaults.xml 数据源映射一致 |
| 3 | 访问分片数据前设置路由，finally 中清理上下文 |
| 4 | 自定义 SQL 使用参数绑定，不拼接用户输入 |
| 5 | 新增/修改数据结构同步 DDL、BO、DAO 和测试数据 |

---

## 三、接口与注册

| # | 检查项 |
|---|--------|
| 1 | 新增接口命名、入参、出参、异常和 serviceCode 符合项目约定 |
| 2 | 对外门面、适配服务和插件服务已同步注册配置 |
| 3 | 修改共享接口前已做影响分析并列出调用方 |
| 4 | 接口目录和 API drilldown 已同步更新 |
| 5 | 错误码、返回消息和日志口径与调用方一致 |

---

## 四、后台任务与外部调用

| # | 检查项 |
|---|--------|
| 1 | 异步任务有幂等键、状态机、重试和终止策略 |
| 2 | 外部调用记录请求摘要、响应摘要、耗时和错误码 |
| 3 | 未知失败先回查或转人工，不盲目重复提交 |
| 4 | 外部服务码、主题、队列、地址和密钥不散落在业务代码 |

---

## 五、测试与验证

| # | 检查项 |
|---|--------|
| 1 | 单元测试覆盖成功、业务失败、系统异常和边界值 |
| 2 | 涉及路由、事务、外部调用或后台任务时有集成冒烟验证 |
| 3 | 测试数据脱敏、可复现、可清理 |
| 4 | 验证结果记录命令、环境、输出和剩余风险 |
