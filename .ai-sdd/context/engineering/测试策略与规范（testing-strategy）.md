# 测试策略与规范（Testing Strategy）

> 本文定义测试上下文的通用结构。具体测试框架、runner 命令、mock 工具、测试数据准备脚本和报告路径必须从目标仓库确认。

---

## 一、测试分层

| 测试层级 | 目标 | 常见证据来源 | 适用范围 |
|---|---|---|---|
| 单元测试 | 验证单个类/方法/组件逻辑 | 现有 test 目录、构建脚本、CI 配置 | 纯逻辑、参数转换、规则判断 |
| Mock 单元测试 | 隔离下游依赖验证服务编排 | mock 框架、已有测试基类、测试夹具 | SV、BFF、组件服务 |
| 集成冒烟测试 | 验证核心链路和真实配置可工作 | runner、环境说明、接口测试脚本 | CSF/HTTP/API、DAO、后台任务 |
| 回归测试 | 覆盖历史缺陷和关键业务路径 | 缺陷记录、验收用例、变更影响面 | 高风险变更和共享能力 |

---

## 二、BSV Mock 单元测试

| 规范项 | 要求 |
|---|---|
| 测试入口 | 优先测试业务编排层或管理服务层，避免只测 DAO 包装代码 |
| 依赖隔离 | DAO、外部系统、跨中心服务、缓存和配置读取应 mock 或使用测试替身 |
| 路由验证 | 涉及分库/CenterFactory 时验证设置和 finally 清理 |
| 异常路径 | 覆盖参数缺失、下游异常、重复调用、状态非法和业务拒绝 |
| 断言 | 同时断言返回值、关键副作用、错误码/异常和调用次数 |

---

## 三、PSV/BFF Mock 单元测试

| 规范项 | 要求 |
|---|---|
| 入参契约 | 覆盖前端必填、可选、默认值和非法值 |
| 会话上下文 | mock 操作员、组织、渠道、区域、租户等上下文 |
| 下游调用 | mock 本地 SV、跨中心接口、HTTP 网关和缓存工具 |
| 响应包装 | 断言 retCode、retMessage、data、分页和空结果口径 |
| 安全 | 验证敏感字段不进入日志和响应中不暴露内部异常 |

---

## 四、测试数据管理

| 数据类型 | 管理方式 |
|---|---|
| 枚举/配置 | 使用测试配置或 mock 返回；记录配置来源 |
| 业务实体 | 使用脱敏样本，保留字段语义，不保留真实身份信息 |
| 数据库数据 | 优先通过 fixture/SQL/构造器生成，测试后清理 |
| 外部接口数据 | 使用契约样本或 mock，不依赖不稳定外部环境 |

---

## 五、测试任务生成规则

| 变更类型 | 必须生成的测试任务 |
|---|---|
| 新增接口 | 成功、必填缺失、权限/会话缺失、下游失败、返回字段契约 |
| 修改规则 | 命中、不命中、边界值、冲突规则、历史兼容 |
| 修改数据访问 | 查询条件、空结果、多结果、异常 SQL、路由/事务 |
| 修改后台任务 | 幂等、重试、失败终止、状态推进、重复调度 |
| 修改前端调用 | 请求参数、Header、响应解析、错误提示、mock 映射 |

## 六、E2E 用例清单规范

| 字段 | 说明 |
|---|---|
| 场景名 | 用户可理解的端到端业务场景 |
| 前置条件 | 必要配置、账号、数据状态和外部依赖 |
| 操作步骤 | 页面、接口或后台任务的触发路径 |
| 预期结果 | 页面表现、接口返回、数据落库、异步状态 |
| 验证证据 | 日志、数据库查询、接口响应、截图或报告路径 |
| 清理方式 | 测试数据回滚、状态恢复或隔离说明 |

> **产物落盘位置**：E2E 用例清单与脚本草稿默认落盘到 `paths.e2e_directory`（change 级，不按 `{repo}` 分目录，不写死到前端仓库 `docs/testing/e2e/`，详见 apply-checklist §七-B）。

---

## 七、测试报告与验证记录

| 内容 | 要求 |
|---|---|
| 执行命令 | 记录完整命令、工作目录和关键环境变量 |
| 结果摘要 | 标明通过、失败、跳过和失败原因 |
| 失败处理 | 给出失败归因、是否阻塞和后续动作 |
| 覆盖说明 | 说明覆盖的需求点、接口、分支和未覆盖风险 |
| 证据链接 | 关联日志、报告、截图、CI 任务或本地输出 |

> **产物落盘位置**：测试源码落 `paths.test_source_directory`、测试报告落 `paths.test_report_directory`、runner 落 `paths.test_runner_directory`（均按 repo 级分目录，含 `{repo}` 占位符）。
