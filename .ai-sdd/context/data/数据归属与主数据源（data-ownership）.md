## 三、数据访问与写入约束

| 约束规则 | 说明 |
| ------ | ---- |
| 主责写入 | 非主责系统不得直接改写权威数据，除非项目明确授权 |
| 读写分离 | 查询优先走可复用接口或只读数据源，写入走主责服务 |
| 分库路由 | 涉及分片数据时必须确认路由键和分库规则 |
| 同步一致性 | 跨系统同步需说明消息、批处理、接口回写或补偿方式 |
| 冲突处理 | 多来源字段冲突时按上下文治理规则记录证据和裁决 |

## 五、context-update 更新要求

更新数据归属时同步检查：

1. `data-model/` 中实体关系和字段字典。
2. `.bo`、DAO 包路径、datasource 映射配置。
3. 接口目录中对该数据的读写 API。
4. 业务规则中依赖该数据的校验规则。
