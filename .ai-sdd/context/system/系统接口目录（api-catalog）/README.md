# 系统接口目录（API Catalog）

> 目录说明：本目录存放系统接口清单、serviceCode、调用入口和查询指南。模板只定义目录结构；具体接口必须由代码扫描、API Registry、GitNexus 或人工确认后填充。

## 文件清单与加载策略

| 文件名 | 内容 | 加载条件 |
|--------|------|---------|
| [概览与查询指南（summary）.md](概览与查询指南（summary）.md) | 接口目录概览、查询路径、归属约束和填充规则 | 需要寻找接口、serviceCode 或复用候选时先加载 |
| 待补充 | 按系统、模块或接口类型拆分的接口清单 | 命中对应系统、模块或接口类型后加载 |

## 推荐加载顺序

1. 先读本 README 和 summary。
2. 根据业务关键词、接口类型、调用方/被调方定位候选清单。
3. 对候选接口再进入 api-drilldown 或源码确认方法级事实。

## 延迟加载建议

- 未明确接口方向时只读 summary，不展开所有接口清单。
- 编码前再加载具体方法、入参、出参、异常和副作用文档。

## 停止继续加载建议

- 找到可复用接口并完成契约确认后，停止继续展开无关接口清单。
