# 核心业务分层模型（Core Layered Model）

> 本文描述通用分层边界。具体仓库、包路径、接口名和服务注册以目标项目证据为准。

---

## 一、核心职责边界

| 层次 | 核心职责 | 禁止事项 |
|------|----------|----------|
| 前端 | 页面交互、展示状态、轻量校验、请求封装 | 承载权威业务规则 |
| PSV/BFF | 前端契约承接、会话上下文、页面级编排、响应包装 | 直接写核心业务表或绕过 BSV |
| BSV/业务服务 | 业务规则、事务边界、状态机、能力复用、对外门面 | 依赖页面对象或散落外部协议细节 |
| DAO/BO/Engine | 数据访问、ORM、SQL、分库路由 | 承载跨系统流程 |
| Adapter | 跨中心、外部系统、消息和协议封装 | 让业务层感知远程服务码或签名细节 |

---

## 二、分层总览

```text
前端应用
  -> 页面网关/HTTP 封装
    -> PSV/BFF 门面接口
      -> PSV/BFF 页面编排服务
        -> BSV 对外门面接口
          -> BSV 业务编排服务
            -> 管理服务/领域服务
              -> DAO/BO/Engine
            -> Adapter
              -> 外部系统/其他中心/MQ
```

---

## 三、BSV 栈各层说明

| 层级 | 名称 | 职责 | 常见证据 | 可调用下层 |
| ---- | ---- | ---- | -------- | ---------- |
| 5 | BSV-CSF/门面 | 对外暴露稳定能力，做协议适配和异常转换 | 服务注册、接口类 | BSV-Service |
| 4 | BSV-Service | 业务编排、事务、幂等、状态流转 | SV 实现、调用链 | 管理服务、Adapter |
| 3 | DAO/管理服务 | 数据访问门面、领域数据能力 | DAO/SV、GitNexus | BO/Engine |
| 2 | BO/IValue/Engine | ORM 映射、实体定义、框架 CRUD | `.bo`、Bean、Engine | 数据库 |
| 1 | DDL/DML | 表结构、索引、初始数据、迁移脚本 | DDL、DB 字典 | - |

### BSV 调用规则

| 规则 | 说明 |
| ---- | ---- |
| 门面薄 | CSF/CSV/GW 门面不写复杂业务规则 |
| 业务集中 | 状态变更、幂等和事务边界放在业务服务层 |
| 数据隔离 | DAO/Engine 不调用页面服务和外部协议 |
| 适配封装 | 跨中心/外部系统调用必须经过 Adapter |

---

## 四、PSV/BFF 栈说明

| 层级 | 名称 | 职责 | 常见证据 |
| ---- | ---- | ---- | -------- |
| 3 | 页面接口/网关适配 | 承接前端 serviceCode、路径、Header | 网关配置、接口类 |
| 2 | 页面服务编排 | 会话、权限、参数转换、下游调用、响应包装 | BFF/PSV 实现 |
| 1 | DTO/VO/协议对象 | 前后端契约、分页、错误口径 | POJO、接口文档 |

### PSV/BFF 调用规则

| 规则 | 说明 |
| ---- | ---- |
| 契约稳定 | 前端契约变更要同步 mock、接口目录和测试 |
| 权限前置 | 会话、渠道、组织、租户等上下文在页面服务层明确 |
| 业务下沉 | 权威业务规则和状态变更下沉到 BSV |
| 响应统一 | 错误码、提示、分页和空结果遵循项目统一包装 |

## 五、新功能定位指南

| 功能特征 | 应放置层次 | 判断依据 |
| -------- | ---------- | -------- |
| 页面展示、按钮、表单 | 前端 | 不改变权威业务状态 |
| 前端接口承接、响应包装 | PSV/BFF | 面向页面交互和会话上下文 |
| 业务规则、状态变更、事务 | BSV-Service | 需要权威业务处理 |
| 表查询、落库、SQL | DAO/BO/Engine | 需要访问数据源 |
| 跨中心、外部系统、MQ | Adapter/后台任务 | 需要协议封装或异步补偿 |
